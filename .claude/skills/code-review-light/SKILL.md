# code-review-light

## レビュー観点

- 今回のタスク範囲を超えた変更がないか
- 型エラーや明らかなビルドエラーがないか
- OS操作やファイル操作が危険な実装になっていないか
- frontendから直接shell実行していないか
- DB schemaと型定義にズレがないか
- ユーザーが手動起動したプロセスを勝手に停止する設計になっていないか

## 出力

- 問題あり / 問題なし
- 修正必須
- 後回しでよい改善
- 次に確認すべきコマンド
