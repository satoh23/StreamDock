## ⚠⚠⚠ 出どころ（[063c](../tasks/063c-gacha-presentation.md) (5) の線引き）

- `gacha-sheet.png` … **依頼者が ChatGPT で生成した自作物**（2026-08-23 提供）。
- ⚠⚠ **[063s](../tasks/063s-tanuesa-gacha-spike.md) で調べた既存ツール（たぬえさ3）の素材は 1 枚も使っていない。**
  親 [063](../tasks/063-gacha-effect.md) の「IP／ライセンス上の線引き」は
  **設定ファイルの形式の再現も素材の流用も不可**としており、本素材はそのどちらにも当たらない。
- ⚠ **音は 1 つも入っていない**（063c (5) の「音を付けたくなったらそこで改めて線を引く」は未着手のまま）。
- ⚠⚠ **本素材について独占的な権利は主張しない**（063c 段 5 の security-review ⑦ で追記・2026-08-25）。
  生成モデルの出力なので、**他者が似た絵を生成しうる**——「第三者の資産を流用していない」ことと
  「他に同じような絵が存在しない」ことは**別の話**である。
  ⇒ ⚠ **他所で似た絵を見かけても、それ自体は本素材の由来を疑う根拠にならない。**
  ⚠⚠⚠ 逆に、**本素材を「StreamDock 固有の意匠」として保護されている前提の判断をしないこと**
  （例: 似た演出を出す他ツールへの申し立て）。

## ⚠⚠ 元シートの置き場は**ここ 1 つ**である

⚠ `.claude/source/` にも同じ画像（依頼者が Claude へ渡すために置いたもの）が在るが、
**あちらは作業置き場で、リポジトリには含めない**（`.gitignore` 済み・sha256 は本ファイルと一致）。
⚠⚠ **同じ 2.6MB を 2 つコミットしないこと**——git の履歴からは二度と消せない
（063c 段 5 の security-review Q-1(9) で実際にコミット直前だった）。

## ⚠ なぜ元シートをリポジトリに残すのか

シートの**透過は自動マット**（生成時に付いたアルファ）で、⚠⚠ **手では二度と再現できない**。
元シートと切り出しの座標表が無いと、次に素材を足したい人が**作り直せない**。

## 使い方

```bash
python3 docs/assets-source/extract-gacha-assets.py
```

`apps/desktop/src/assets/gacha/` を**作り直す**（13 枚・約 552KB）。

⚠⚠ **これはビルドの一部ではない。** 生成物はコミットしてあるので、
**アプリのビルドにも CI にも Python は要らない**（＝ 063 の「新規依存ゼロ」を守るための構え）。
⚠ 切り出しの方針（拡大しない／連番は**同じ高さ**の箱で切り絵を中央に置く／見出しの帯を消す／
**文字が焼き込まれた素材は使わない**）は、スクリプト冒頭の docstring が正。

| 項目 | 実測 |

これは 061l が「同梱 PNG は要るか → **絵文字だけ**」と結論した先例の、素直な拡張である。

## ⚠⚠⚠ 使っていない素材と、その理由

| 素材 | 理由 |
|---|---|
| 「大当たり！」のテロップ ／ 同じ文字が入ったカード（開封 **6** コマ目） | ⚠⚠⚠ **どの景品が当たっても「大当たり」と出る**のは視聴者に対する嘘になる（当たりやすさは景品ごとに違う）。⇒ 中立な「ガチャ！」「パカッ！」だけを使い、**景品名はアプリが文字として描く** |
| 「？！」 | 同上（何を指しているのか演出の側で決まらない） |
| ~~「レア！」~~ | ⚠⚠⚠ **063c 段 3 で解禁した**（表の「使っていない素材」から外れた）。当たりやすさは **`prize.weight` ＝ ユーザーが打った％そのもの**（分母は 1000 固定）なので、**「10% 未満」は測れるし嘘にならない**。⚠ 判定は `isGachaRarePrize` 1 か所・**結果の段にだけ出す**（抽選中に出すと結果が漏れる） |
| ガチャマシン 6 コマ目（一番右） | ⚠⚠⚠ **排出されるカプセルの色が違う**（青／桃・開封の連番は赤／白）。挟むと「**青いカプセルが出てきて、赤いカプセルが割れる**」になる |
| 金／青／桃／緑のバースト、光球、紙吹雪、煙、スポットライト、リング、GACHA! リボン | ⚠ 063c 段 2-c: **バーストと光球は一度使ってやめた**——実機で**画面の半分を光が占めて、景品名より強かった**。⇒ 金の粒 1 枚だけにした |
| セクション 7（遷移用背景） | 上表のとおり解像度が足りず、枠線ごと写る |
| セクション 4（テキスト表示ボックス） | 景品名が可変長（最大 24 文字）で枠に収まらない |
| セクション 9（透過済み完成アニメーション例） | **例示**であって素材ではない（市松模様が絵として描かれている） |
