## StreamDock を公開しました

配信の準備に使うツールを **プリセット単位でまとめて起動・停止**できるデスクトップアプリです。

## できること

- **プリセット** … よく使うツールをひとまとめにして、ワンクリックで全部起動・全部停止できます。
- **個別の起動・停止** … プリセットの中のツールを 1 つずつ起動・停止することもできます。
- **ツール登録** … アプリや URL を登録できます。アイコンは登録したアプリから自動で取り込みます。
- **自動起動** … PC のログイン時に、指定したプリセットを自動で立ち上げられます。
- **らくらくツール設定** … 配信でよく使うツールの導入と設定をアプリ内から案内します。
- **内蔵コメントビューア** … YouTube と Twitch のコメントを**同時に**表示できます。
- **コメントの見やすさ** … 初見さん・初コメントの色分け、コメントの固定に対応しています。
- **視聴者メモ** … 視聴者ごとにメモを残せます。メモはこの PC の中だけに保存されます。
- **読み上げ** … VOICEVOX と連携してコメントを読み上げます（話者の選択・試聴ができます）。
- **OBS 用オーバーレイ** … 背景が透過したコメント表示ウィンドウを OBS に取り込めます。
- **OBS への自動追加** … 上のオーバーレイを OBS のシーンに自動で追加できます。
- **表示設定** … ライト / ダークテーマを切り替えられます。
- **診断画面** … 動作ログとアプリのバージョンを確認できます。

## 使うために必要なもの

- **コメントビューア** … YouTube・Twitch それぞれで**アプリからのログイン**が必要です。使う配信サービスだけ接続すれば大丈夫です。
- **読み上げ** … **VOICEVOX を別途インストールして起動**しておく必要があります。StreamDock だけでは読み上げできません。
- **OBS への自動追加** … OBS 側で **obs-websocket を有効**にし、設定で「OBS に自動で反映する」を ON にしたときだけ動きます。有効化の手順はアプリが案内します。

## 補足

- macOS 版は**未署名**のため、初回は右クリック →「開く」で起動してください。
- Windows 版は初回に SmartScreen の警告が出ることがあります（「詳細情報」→「実行」で起動できます）。
