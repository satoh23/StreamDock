# 064 エフェクトを「OBS 側のソースを鳴らす」方式へ転換する

> **必読前提**: [061 OBS エフェクト](061-obs-effects.md)（**この文書が覆す決定がある**）、
> [044s OBS WebSocket スパイク](044s-obs-websocket-spike.md)（方式決定）、
> sidecar の OBS クライアント [`obs/obs-client.ts`](../../apps/comment-sidecar/src/obs/obs-client.ts)、
> [`docs/security.md`](../security.md) §1（外部通信）／§3（コマンドは単一目的）／§9（第三者データ）。

## ⚠⚠ これは 061 の設計判断 (1) を覆す

061 は **「エフェクトは専用の透過窓 ＋ OBS ウィンドウキャプチャで出す」**（＝**StreamDock が窓の中に描く**）
と決め、その上に取り込み（061c）・UI（061d）・条件（061j）・2 窓化（061k）・
mp4/mov（061q）・背景の透過（061r）・コーデック判定（061s）を積んできた。

064 はこれを反転する:

> **こっち側で映像の保存や取り込みをするのではなく、OBS 側で設定させて、
> 設定させたものを特定の条件が発動した時にこっちで再生させる**（依頼者・2026-08-15）

## なぜ転換するのか

| 061 の方式 | 064 の方式 |
|---|---|
| ユーザーがファイルを StreamDock に**取り込む** | ユーザーが OBS に**ソースを置く**（配信者に馴染みのある操作） |
| 透過は StreamDock が WebGL で抜く（061r） | **OBS 標準のクロマキーフィルタ**で済む |
| コーデックは StreamDock が判定して弾く（061s） | **OBS が再生できるものは何でも**（ProRes も HEVC も） |
| 位置・大きさ・秒数は StreamDock の編集画面 | **OBS 上で自由に**（フィルタも変形も） |
| 100MB 級の data URI が IPC を通る | **1 バイトも通らない**（表示指示だけ） |
| ディスクを最大 4.25GiB 使う（32 × 136MiB） | **0** |

⚠⚠ **セキュリティ面が大幅に軽くなる**——ファイル読み取り・サイズ上限・マジックバイト・
symlink 拒否・data URI・第三者 JSON が**すべて不要**になる。

## ⚠⚠ 代わりに増える唯一の面

**「viewer から来た文字列（OBS のソース名）が OBS 操作へ渡る」経路**である。
044a 以来、sidecar が OBS へ渡す名前は `OBS_OVERLAYS` の**固定 4 値**だけで、
それが docs/security.md §3 / §8 の担保だった。

⇒ **壁を 2 枚立てる**（064a で実装済み）:

1. **形式検査**（`isAllowedObsSourceName`）… 型・空・200 文字・制御文字
2. ⚠⚠ **実在検査**（`GetInputList` との照合）… **こちらが本体**。OBS に無い名前は 1 回も操作へ渡らない

そのうえで **できる操作は 3 つだけ**（表示 / 非表示 / 頭出し）。
⚠ **ソースを作る・消す・設定を書き換える能力は持たない**（§3 の単一目的を維持）。

### ⚠ 064b で計画から外した 2 点

1. **接続の維持** … 相手は localhost で往復は数ミリ秒＝**測っていない最適化**になるため見送った。
   **再修正トリガー＝実機で「反応が遅い」と感じたとき**（そのとき §1 へ姿勢の追補が要る）。
2. **判定層の「移設」** … 実際にやったのは**移設ではなくレーンの追加**である。エフェクト窓（テンプレート）は
   そのまま残し、コメビュ窓に **OBS 用のレーンを 1 本足した**。⚠ 移設だと 064d まで
   **テンプレート方式が動かない期間**ができるため（「削除は最後」と同じ理由）。

### ⚠ 表示時間の決め方（064b で確定）

**OBS に聞く**（`GetMediaInputStatus` の `mediaDuration`）。⇒ 設定項目を 1 つも増やさずに
「動画が途中で切れる」が消える。⚠ 上限 15 秒のクランプは**残す**（外すと「消えない」が復活する）。

## 受け入れ条件（064 全体）

- ✅ コメントの条件（キーワード・イベント）が当たると、**OBS 側のソースが頭出しされて出て、指定秒数で消える**（064b）
- ✅ ⚠ **消し忘れが起きない**（＝配信画面に出しっぱなしにならない。sidecar 側でクランプ＋タイマー再張り）
- ✅ OBS 未接続・ソース未設置のときに**黙って何も起きない状態を作らない**（画面で理由が読める）
  ——⚠⚠ **064c まで成立していなかった**（`listSources` が失敗も 0 件も空配列で返しており、
  **OBS が落ちているユーザーへ「OBS にソースを追加しろ」と誤案内していた**）
- ✅ 取り込み機能が消えても、既存ユーザーの移行コストが**ゼロ**であること（064d・移行コード 0 行）
  （⚠ version `0.1.0`・`git tag` 0 件＝**未リリース**なので、061f と同じ論法が使える）

⚠ **4 つとも実装は済んだ**（064c の実機確認と security-review が残っている）。
