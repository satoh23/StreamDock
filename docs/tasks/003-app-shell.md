# 003 App Shell

## 目的

stream-dock のアプリ基本画面構成（レイアウト・画面遷移の骨組み）を React で作る。
以降の機能実装（ツール登録・プリセット等）を載せる土台となる UI シェルを用意する。

## やること

- アプリ全体のレイアウト（ヘッダー / サイドナビ or メイン領域）を作る
- 主要画面のプレースホルダーを用意する（例: プリセット一覧 / ツール一覧 / 設定）
- 画面切り替え（ローカル state ベースのシンプルなナビゲーション）を作る
- 静的なダミー表示で画面構成が確認できる状態にする
- 既存の初期 App.tsx（雛形）をアプリシェルへ置き換える

## やらないこと

- SQLite の導入・データ永続化
- Tauri command（invoke）の追加・呼び出し
- プロセスの起動 / 停止
- 保存処理・状態の永続化
- ツール登録 / プリセット CRUD などの機能ロジック

## 完了条件

- `pnpm tauri dev` で基本画面構成が表示される
- プレースホルダー画面を切り替えできる
- `pnpm typecheck` / `pnpm lint` が通る
- docs/progress.md に結果が追記されている

## 補足

- ナビゲーション方式は「ライブラリ追加を避けローカル state で実装」を既定とする。
  CLAUDE.md「新ライブラリ追加は理由説明が必要」に沿い、react-router 等は本タスクでは導入しない。
