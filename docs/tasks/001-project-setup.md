# 001 Project Setup

## 目的

stream-dock のTauri + React + TypeScript開発環境を作る。

## やること

- Tauri + React + TypeScript の雛形を作る
- pnpm を使う
- アプリ名を stream-dock にする
- 開発起動できることを確認する
- 最小のディレクトリ構成を整える
- READMEに起動方法を書く

## やらないこと

- ツール登録機能
- プリセット作成機能
- SQLite導入
- プロセス起動
- UI作り込み

## 完了条件

- pnpm install が通る
- pnpm tauri dev が起動する
- 初期画面が表示される
- docs/progress.md に結果が追記されている
