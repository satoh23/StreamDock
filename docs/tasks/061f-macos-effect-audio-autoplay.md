## 結論（3 行）

1. **起票理由（非フォーカス窓で autoplay policy に拒否される）は誤りだった**——
   `wry 0.55.1` が `setMediaTypesRequiringUserActionForPlayback(None)` を既定で呼んでおり、
   **macOS の autoplay policy は 5 窓とも最初から無効化されている**（`tauri-runtime-wry` は触っていない）。
2. **本当の原因は音源のデコード可否だった**——**macOS の WebKit は Ogg コンテナをデコードできない**。
   ⚠ コーデックではなく**コンテナ**が拒否されている（Vorbis も Opus も落ちる）。
3. ⇒ **`audio/ogg` を Rust と TS の両層から落とした**。許可する音源は **`wav` / `mp3` の 2 種**。

## なぜ「許可のまま UI で伝える」ではなく「落とす」を選んだか

- ⚠⚠ **落とすほうが 061c の約束（取り込めた＝使える）を守る。** 許可したままだと
  「取り込めるのに macOS でだけ無音」＝約束が破れたまま文言で謝ることになる。
  落とせば取り込んだ瞬間に「音源は .wav / .mp3 のいずれかにしてください。」と言え、
  **変換すればよいことまで伝わる**。
- **移行コストがゼロだった**——`git tag` 0 件・version `0.1.0` ＝ **テンプレート機能は未リリース**で、
  ogg で取り込み済みのユーザーが存在しない。
- ⚠ **OS 別分岐は採らない**——`scripts/check-effect-template-contract.mjs` が両層を**静的に**
  突き合わせているので崩れるうえ、「OS によって取り込めたり取り込めなかったりする」形は
  テンプレートを配る側が最も混乱する。
