| いま | 変更後 |
|---|---|
| 見出し「OBS のソースを鳴らす」 | **「OBS のエフェクトを再生」** |

⚠ **型名・ファイル名の `ObsSource*` は据え置き**——あちらは obs-websocket の `GetInputList` が返す
「input（ソース）」と 1 対 1 で対応しており、**UI の言い換えのために sidecar・wire との対応を崩さない**。

### ⚠ 情報を 1 つ失っている（受容・依頼者の判断）

削除した「いま OBS で表示しているシーンに置いてあるソースだけ再生できます」は、
**現在のシーンに置かれていないソースが OBS の仕様（scene item が無い）で出せない**ことの唯一の説明だった。
064a はこれを「**書かないとバグとして報告される**」として置いていた。

⚠⚠ **再修正トリガー＝「一覧に出るのに再生されない」と実機で言われたとき。**
そのときは**常時表示の note を戻すのではなく、再生が失敗した行にだけ**理由を出すこと。

## ② 削除した文は、064d 以降**嘘だった**

> 条件を 1 つでも設定すると、配信画面用のウィンドウが自動で開きます。

- 正しかったのは 061i〜064c の間だけ。`useEffectTemplates` が
  「**条件が 0 → 1 件になったら `STAGE_OVERLAY_ENABLED_KEY` を立てる**」という派生値を持っていたため。
- ⚠⚠ **064d でその hook ごと削除し、旗の意味を「いま配信イベントでステージ窓を使っているか」へ移した。**
  ⇒ **条件をいくつ作っても窓は 1 ミリも開かない。**
- ⚠ 061p が「⚠ **消さないこと**」と書いていた根拠（表示トグル廃止後に「いつ窓が開くのか」を
  説明する唯一の場所）は、**その挙動ごと無くなったので失効している**。

⚠ **いま「窓が開く契機」を説明しているのは [`StreamEventTab`] の
「『開始』を押すと、配信画面用のウィンドウ（…）が…」1 か所**（＝実際に開く場所）。

## ③ 「OBS へ自動で反映」は**何も起こしていなかった**

追いかけた結果:

| 段 | 実態 |
|---|---|
| トグルの読み手 | `CommentViewerApp` の `scheduleObsAutoAdd("stage")` **1 か所だけ** |
| 何を追加するか | ⚠ **OBS のソースではなく「ステージ窓」**（配信イベントを StreamDock が描く窓） |
| 窓が開く契機 | **配信イベントの「開始」だけ**（064d でそうした） |
| ⚠⚠ 配信イベントの数 | `STREAM_EVENT_REGISTRY` が **`[]`**（061p で見本を削除）＝ **「開始」ボタンが存在しない** |

⇒ **ステージ窓は開きようがなく、トグルを ON にしても最後まで何も起きない。**

### ⚠⚠⚠ 「削除」ではなく「既定 ON 化」にした（依頼者の指示）

> OBS に自動で反映はデフォルト機能にします

機能そのものは玉入れ（061l の続き）で必要になるので、**反映処理は残し、ゲート（トグル）だけを外した**。

- 削除: `EFFECT_OBS_AUTO_ADD_KEY` / `loadEffectObsAutoAdd` / `saveEffectObsAutoAdd` / カード / トグル
- 無条件化: `CommentViewerApp` の 3 か所（開始時 `scheduleObsAutoAdd` ／ 終了時 `requestObsHide` ／
  WS 接続時 reconcile）
- 丸ごと削除: `EFFECT_OBS_AUTO_ADD_KEY` の `storage` 分岐（67 行。**発火する契機が 1 つも無くなった**）

⚠ **044a の `OBS_AUTO_ADD_KEY`（コメント一覧＋固定コメント用・コメビュ窓の設定カード）は無改変。**
あちらは**常設のオーバーレイ窓**が対象で、「開始ボタン」のような明示操作に紐づいていないため、
同じ理屈で既定 ON にはできない。

## ⚠⚠ ゲートを外したら壊れた 2 点（明示的に守り直した）

### 1. `localStorage.clear()` が OBS へ `hide` を送り始める

061a レビュー Q-4 は「`clear()` に副作用を持たせない」を受容していたが、**その担保は
`loadEffectObsAutoAdd()` が `clear()` で false になることに頼った偶然**だった。
⇒ **`e.key !== null` を明示的に足した**（＝消したゲートが果たしていた役割の埋め合わせ）。

### 2. 061e 穴 1（共有 `obsState` を巻き添えで倒さない）の入口が消える

`clear()` ぶんの後始末（`!loadObsAutoAdd()` のときだけ idle へ）を
**`STAGE_OVERLAY_ENABLED_KEY` 分岐へ移設**した。

## ⚠ §1 の停止導線はカードの外へ出して残した

⚠⚠ **`docs/security.md` §1 が名指しする main 窓側 1 か所**なので、カードごと消してはならない。
⚠ 1 文目を書き直した——旧文は「OBS **への反映**は行われません」で、消えた自動反映カードだけを
