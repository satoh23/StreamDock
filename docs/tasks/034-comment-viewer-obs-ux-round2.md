## 目的

内蔵コメントビューア（別ウィンドウ label `comment-viewer` / 実体
[`CommentViewerApp.tsx`](../../apps/desktop/src/screens/comment-viewer/CommentViewerApp.tsx)）と OBS 透過オーバーレイ
（label `comment-overlay` / 実体 [`OverlayApp.tsx`](../../apps/desktop/src/screens/comment-viewer/OverlayApp.tsx)）は、
033 系（第1弾）で「配信中に実運用できる UI」の土台まで到達した。だが**本番でギリギリ使えるレベル**にとどまり、UX が悪い。
本タスク群（第2弾）は、実運用で表面化した以下の 7 点を潰し、コメビュ/オーバーレイを「見やすく・状態が分かる」水準へ引き上げる。

現状の主な問題（本人指摘）:

1. OBS オーバーレイの表示状態が分からない（開閉ボタンが常にグレーで、開いているのか閉じているのか不明）。
2. VOICEVOX 話者選択時にどんな声か分からない（サンプル試聴が無い）。
3. OBS オーバーレイのデザインがダサい。
4. OBS オーバーレイの表示設定が設定画面に無い／デザインを選べる項目が欲しい（プレビュー付き）。
5. コメビュ・オーバーレイが最新コメントに自動追従しない（手動スクロールしないと見切れる）。
6. OBS オーバーレイの文字が小さくて読みにくい。
7. OBS オーバーレイに（既定の）スクロールバーが「サイドバー」として出てしまう。

## 確定した方針

- **採番は新規親 034**（033 は第1弾として完了扱い・[`docs/task-board.md`](../task-board.md) の Done へ移す）。第2弾であることを明確にする。
- **オーバーレイ意匠は段階的に進める**。今回（034e）は「**背景透過・コメント本文＋アカウント名のみ**」の**単一デザイン**へ
  刷新し、**サイト名（配信サービス）表示の ON/OFF トグル**を付ける。**複数デザイン＋画像/GIF プレビュー選択 UI は
  本バッチでは作らず将来枠**（「このタスク（親）でやらないこと」参照）。理由: 複数デザイン定義＋プレビュー素材＋選択 UI は
  実装量が大きく、まず「見やすい 1 デザイン」を最短で届けて実運用の可読性を確保するため。
- **設定はコメビュ窓の設定ビュー [`SettingsView.tsx`](../../apps/desktop/src/screens/comment-viewer/SettingsView.tsx) に集約**
  （033b で新設）。オーバーレイの表示 ON/OFF・デザイン設定もここへ寄せる。**理由**: 接続の sidecar 通信はコメビュ窓に
  閉じており、設定を**メイン窓** [`SettingsScreen.tsx`](../../apps/desktop/src/screens/settings/SettingsScreen.tsx)（テーマのみ）へ
  置くと no-internet 境界（§1 /「コメントビューア方針②」）との整合が崩れる。メイン窓の設定画面は**変更しない**。
- **1 タスク 1 機能で分割**（CLAUDE.md）。034a〜e ＋ 本親 034。

推奨: **034a → 034b** を逐次、**034c** を並行、**034d → 034e** を逐次。034a で入れる「下端追従」の仕組みを 034b が

## 横断セキュリティ方針（docs/security.md 準拠）

- **メイン窓の no-internet 維持が最優先**。オーバーレイ設定・接続 UI はコメビュ窓（設定ビュー）に閉じ込め、メイン窓・
  その Rust command に通信面を増やさない（§1 /「コメントビューア方針②」）。オーバーレイは**表示専用**（loopback WS
  読み取り専用接続のみ・制御フレームを送らない）を維持する。
- 新規 npm/crate/plugin・新規外部通信・`csp` 変更は原則入れない。VOICEVOX 試聴（034c）はループバック `127.0.0.1:50021`
  の例外（032c-c）内・既存メソッド（`/audio_query`・`/synthesis`）の再利用に留める（新規エンドポイントを足さない）。
- **既存挙動（Twitch/YouTube 取得・VOICEVOX 合成読み上げ・オーバーレイ透過表示・no-orphan kill 契機）を壊さない**線引きを
  各サブタスクの「このタスクでやらないこと」で明示する。オーバーレイの close で sidecar を落とさない現行を維持（034d）。
